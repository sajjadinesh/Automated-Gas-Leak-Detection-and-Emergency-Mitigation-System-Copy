# Automated Gas Leak Detection and Emergency Mitigation System

An embedded safety system built with an Arduino Uno, an MQ gas sensor, an LCD monitor, and an automated exhaust ventilation relay.

## Features
- Real-time air quality sampling using an MQ gas sensor
- 16x2 LCD display showing live PPM levels and status (`SAFE` vs `ALERT`)
- Visual and audio warnings: Green LED for normal, Red LED + Buzzer for gas leaks
- Active mitigation: 5V relay module triggers an exhaust fan whenever gas exceeds 100 PPM
